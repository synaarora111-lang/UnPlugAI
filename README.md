# UnPlugAI
Reclaim your human focus, protect critical thinking, and transform mindless AI consumption into intentional cognitive work.

📖 Overview

UnplugAI is a privacy-first digital wellness web application designed to help individuals, developers, and students break reflexive generative AI reliance. As tools like ChatGPT, Claude, and Copilot become deeply integrated into daily workflows, it is easy to default to automated prompting before attempting independent problem-solving.

UnplugAI acts as a mindful friction gate and cognitive tracking dashboard. It encourages a "Draft First" philosophy—prompting users to pause, reflect, and evaluate whether human cognition or AI assistance is best suited for the task at hand.

✨ Key Features

🛡️ Intentional Friction Gate: A 10-second reflection overlay with guided breathing and critical self-check questions ("Can I solve this with 5 minutes of direct thinking?", "Have I created a rough draft first?").

⏱️ Dual-Intent Session Tracking: Categorizes AI tool usage into Intentional (structured research, tutoring) versus Reflexive (mindless delegation, default impulse) to expose subconscious habits.

🏆 Cognitive Wins Journal: A dedicated log to document complex tasks, code debugs, or creative pieces accomplished 100% human-driven.

📊 Interactive Analytics: Visualizes daily AI usage vs. customizable daily caps, 7-day/30-day trend charts (powered by Chart.js), and reflex usage percentages.

🏅 Badges & Streak Mechanics: Earn achievements and track non-AI streak counters for staying within healthy cognitive budgets.

🔒 Privacy-First Storage: Operates completely client-side. All session data stays in your browser's localStorage with zero tracking, backend servers, or third-party telemetry.

🛠️ Tech Stack

Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)

Styling: Tailwind CSS (via CDN)

Visualizations: Chart.js

Icons: Lucide Icons

🚀 Quick Start

Since UnplugAI is built as a lightweight, single-file web application, no complex installation or package management (npm / yarn) is required.

Local Execution

Clone the repository:

git clone https://github.com/your-username/unplug-ai.git
cd unplug-ai


Open the app:
Simply double-click index.html or run one of the following terminal commands:

# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html


🌐 Deployment Options

You can easily host your own instance of UnplugAI using static web hosting:

Vercel Drop

Visit vercel.com/drop.

Drag and drop your index.html file or folder into the upload window.

Your live link will be generated in seconds.

GitHub Pages

Push your repository to GitHub.

Go to Settings > Pages.

Under Build and deployment, select main (or master) branch as the source and click Save.

Access your live site at https://yourusername.github.io/unplug-ai/.

🧠 The UnplugAI Philosophy

Protect Skill Retention: Outsourcing initial thought processes erodes long-term problem-solving intuition and deep focus capacity.

AI as a Tutor, Not a Crutch: Use AI to review, refine, or explain—never to bypass core cognitive effort.

Celebrate Unaugmented Output: Taking pride in raw human creativity and direct critical thinking is essential for meaningful work.
